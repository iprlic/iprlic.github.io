{% comment %} Course JSON-LD for a course page, built from the page's own front matter so it cannot drift from the copy. Included by _layouts/base.html when the page has a `course:` block. course: level educationalLevel (Beginner / Intermediate / Advanced) exam optional exam the course prepares for; emitted as `about`. Never emitted as educationalCredentialAwarded: the course is exam preparation, the certification comes from Anthropic. workload ISO 8601 duration of the course (P1D, P2D, P3D) price_from optional; only a price that is published on the page ("from EUR 4,000" for courses of one to two days). Without it the Offer says Paid and carries no price. instances optional list of { mode, workload }; default is the same course online and on site in Europe. Derived from the page: name (header.title), description, the "what you'll be able to do" column of the overview section (teaches), the first column of the exam section (coursePrerequisites), and the modules (syllabusSections). dateModified comes from `last_updated`. {% endcomment %} {% assign c = page.course %} {% assign course_url = page.url | absolute_url %} {% assign overview = page.sections | where: "section_id", "overview" | first %} {% assign outcomes = overview.columns | last %} {% assign exam_section = page.sections | where: "section_id", "exam" | first %} {% assign prereq = exam_section.columns | first %} {% assign modules = page.sections | where: "section_id", "modules" | first %}
